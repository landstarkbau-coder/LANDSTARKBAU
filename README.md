## 📋 Опис проекту

**LANDSTARKBAU** — це сучасний багатомовний веб-сайт для компанії з ландшафтного дизайну та будівництва. Проект побудовано з використанням Next.js 16, Prisma 7, Neon PostgreSQL та Tailwind CSS.

### 🌍 Підтримка мов
- 🇩🇪 Німецька (DE)
- 🇬🇧 Англійська (EN)
- 🇺🇦 Українська (UA)
